Overview

A config-driven Plotly Dash web application for monitoring clinical trial biomarker collection progress. The dashboard visualizes collection rates across multiple derived biomarker types — plasma, serum, and PBMC — constrained to visits where the primary blood sample was collected, with interactive charts and per-visit metrics across a simulated 100-participant cohort.

Tech stack

  • Dash 4.1.0 and Dash Bootstrap Components 2.0.4
  • Plotly 6.6.0 for interactive charts
  • Pandas 2.3.3 for data manipulation
  • PyYAML 6.0.3 for config parsing

Key features

  • Multi-tab interface for blood, plasma, serum, and PBMC collection.
  • KPI cards for overall collection rate, collected samples, missed samples, and participants.
  • Per-visit bar charts with collection percentage overlays and a 50% threshold reference line.
  • Participant distribution histogram and participant-by-visit heatmap.
  • YAML-defined datasets, source constraints, UI settings, colors, and chart dimensions.

Distribution modes

Web
Dash app with Render/Heroku-style Procfile; reads PORT from the environment.
Desktop — native window
PyInstaller build that opens in a native WebGUI window and works offline.
Desktop — browser
PyInstaller build that opens the user’s default browser and works offline.
Static HTML
Self-contained snapshot with Plotly.js inlined for email or cloud sharing.
