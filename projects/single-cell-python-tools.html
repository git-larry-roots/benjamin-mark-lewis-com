Overview

A Python package of Scanpy wrappers and utility functions for streamlined single-cell RNA-seq analysis. Designed to operate natively on AnnData objects, the package supports both a function-based API for modular step-by-step control and an object-oriented DATASET_class interface for method-chained pipelines from raw counts through clustering, differential expression, and cell type annotation.

Tech stack

  • Python 3.10, Scanpy, AnnData, Leiden clustering, UMAP, and BBKNN.
  • GSEApy, NumPy, Pandas, SciPy, Scikit-learn, Matplotlib, Seaborn, and Numba.
  • Conda or editable pip install workflows.

Key features

  • QC filtering with mitochondrial, ribosomal, hemoglobin, and MALAT1 gene annotation.
  • Normalization, scaling, highly variable gene selection, PCA, and UMAP projections.
  • Leiden clustering with silhouette score analysis for objective resolution selection.
  • Cell cycle scoring/regression and BBKNN batch correction for multi-sample datasets.
  • QC plots, UMAP marker overlays, silhouette plots, batch-effect charts, DEG analysis, GSEA, and cell type annotation.

Example usage

import sctl.pp as pp
import sctl.pl as pl

pp.calculate_qc_metrics(adata)
pp.filter_cells(adata, min_genes=200, max_pct_mito=20)
pp.normalize_and_scale(adata)
pp.run_pca(adata)
pp.leiden_clustering(adata, resolution=0.5)

pl.plot_umap(adata, color=["leiden", "CD3D", "CD14"])
pl.plot_silhouette(adata)
