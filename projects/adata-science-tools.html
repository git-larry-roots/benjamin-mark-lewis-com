Overview

An AnnData-native Python toolkit for differential analysis, scientific visualization, and reproducible simulation workflows. It brings common analysis patterns and plot types into one consistent interface for exploring and communicating multi-omic results.

Key features

  • Differential analysis: coordinated views of effect sizes, statistical significance, and feature-level distributions.
  • Scientific visualization: forest and meta-analysis plots, correlation views, longitudinal and paired data, survival curves, heatmaps, rank diagnostics, and volcano plots.
  • Reproducible examples: documented workflows built from simulated data make plot behavior easier to understand and reuse.
  • Paired analysis: robust support for paired and nested study designs.
  • Data simulation: config-driven AnnData generation with tunable effects, covariates such as age and case/control status, and residual variance.
  • AnnData-native: all tools operate directly on AnnData objects for seamless integration with Scanpy workflows.

Running the examples

git clone https://github.com/gitbenlewis/adata_science_tools.git
conda env create -f config/env_not_base.yaml -n not_base
conda activate not_base

# OLINK proteomics differential analysis
bash example_PMID_33969320/scripts/000_run_everything.bash

# Simulated data with configurable covariates
python example_simulated_data/scripts/simulate_1_var_covar_age.py
python example_simulated_data/scripts/plot_dotplot_simulate_1_var_covar_age.py

# Regenerate the deterministic plotting gallery
bash scripts/000_generate_plotting_gallery.bash
