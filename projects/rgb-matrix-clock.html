RGB Matrix Clock

At a glance

A compact hardware side quest

A CircuitPython clock combining RTC-backed timekeeping, environmental sensing, and on-device controls.

Overview

This project is a hardware clock build powered by CircuitPython on a Raspberry Pi Pico-class board and a Waveshare 64×32 RGB matrix panel. It combines local sensor input with RTC-backed timekeeping and a compact on-device menu for display control.

Hardware stack

  • Raspberry Pi Pico-class board, with UF2 builds targeting Pico 2 W.
  • Waveshare 64×32 RGB matrix panel.
  • DS3231 RTC over I2C.
  • DHT22 temperature/humidity sensor.
  • Photoresistor for ambient light sensing.
  • Three buttons for menu navigation.

Firmware structure

  • code.py: main loop, refresh cadence, and fault recovery reload.
  • display_manager.py: matrix and label object setup.
  • display_updates.py: time/date rendering, animations, and sensor display updates.
  • brightness.py: auto/manual dim logic and color scaling.
  • menu.py: button handling and menu state transitions.
  • sensors.py: DS3231, DHT22, and photoresistor initialization.

Key features

  • Animated 24-hour time display with date and weekday row.
  • Temperature and humidity readout.
  • Scrolling banner text.
  • Auto brightness with manual override.
  • Menu controls for brightness mode and dim level.

Setup summary

  1. Flash the CircuitPython UF2 from RGB_scroll_clock_0215/.
  2. Copy firmware files and lib/ dependencies to CIRCUITPY.
  3. Confirm wiring in config.py pin mappings.
  4. Set display text, colors, and brightness defaults in config.py.
  5. Reboot and verify menu controls and sensor updates.
